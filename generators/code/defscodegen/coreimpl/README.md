# Defs Codegen core implementation

Default distinct `yamldefs`, `jsondefs`, and `xmldefs` frontends plus Java/Python generation backends. Package namespace: `eu.algites.tool.codegen.defs`; `coreimpl` is only an artifact boundary.

The default Java and Python backends propagate canonical descriptions into Javadoc/docstrings and preserve property descriptions in generated data-object documentation. Java records and Python dataclasses generated by this tool use `AIcgd..._N`; non-generated data objects use `AIcd...`.
